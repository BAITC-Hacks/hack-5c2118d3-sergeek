# Sergeek Campaign Agent — сценарий защиты

## Питч на 3 минуты

### 0:00–0:25 — проблема

Маркетинговый аналитик должен выбрать аудиторию, новый тариф и канал связи, но
эффект на целевой базе неизвестен. Кампания вслепую может потратить бюджет и
снизить ARPU. Поэтому наше решение сначала покупает информацию небольшими
пилотами, а затем масштабирует только подтверждённые гипотезы.

### 0:25–1:05 — агент

Sergeek начинает с 15 гипотез, полученных из исторических данных. Он проводит
10 бесплатных push-пилотов по 120 абонентов, ранжирует результаты и повторно
проверяет четыре лучших направления на выборках по 200 человек.

Решение не полагается только на среднее значение. Для каждого направления
агент считает взвешенный observed lift, standard error и uncertainty-adjusted
lower bound. Кампании с отрицательной нижней оценкой не масштабируются.

### 1:05–1:35 — оптимизация портфеля

Для непересекающихся аудиторий агент совместно перебирает skip, push, SMS и
digital ads. Он учитывает размер сегмента, predicted ARPU, стоимость контакта,
множитель канала, остаток бюджета и охвата. Результат — готовый исполнимый
портфель, а не просто рейтинг гипотез.

### 1:35–2:25 — демонстрация

1. Открыть Overview: показать baseline, бюджет, контакты, пилоты и финальные
   кампании.
2. Открыть Campaign Portfolio: показать текущий тариф, ARPU-сегмент, целевой
   тариф, канал, стоимость и pilot lower bound.
3. Открыть Agent Intelligence: показать observed lift, standard error и lower
   bound — это реальные результаты пилотов, а не UI-оценка.
4. Открыть Simulation: показать устойчивость на разных seed.

### 2:25–2:50 — результат

На локальной mock-модели организаторов агент прибыльный в 100 из 100 прогонов:
медиана 3,63 млн условных единиц, минимум 2,02 млн. На контрольном seed он
выбирает пять кампаний, использует 48 180 из 100 000 бюджета и остаётся внутри
всех лимитов.

### 2:50–3:00 — ценность

Главная ценность Sergeek — автоматизация полного решения маркетингового
аналитика: исследовать неизвестную аудиторию, оценить риск, выбрать каналы и
выдать готовый план, который можно объяснить и проверить.

## Важные формулировки

- Все данные синтетические.
- Результаты dashboard — local mock simulation, а не гарантия результата на
  скрытой модели.
- Agentic AI здесь — автономный цикл observe → estimate uncertainty → decide →
  allocate, а не обязательный вызов LLM.
- В строке «19 кампаний» evaluator считает 14 пилотов и 5 финальных кампаний;
  лимит 10 относится к финальному списку агента.

```bash
docker compose exec api python -m unittest discover -s tests -v
```
