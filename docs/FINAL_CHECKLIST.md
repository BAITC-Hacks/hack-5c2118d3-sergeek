| Требование | Проверка и результат |

| ≤20 пилотов по 10–200 клиентов | 12 × 100 + 5 × 160 |
| ≤5 000 клиентов на финальную кампанию | Соблюдено; проверяется контрактными тестами |
| submission.csv воспроизводится | Генерация в отдельном контейнере успешна; сравнение с репозиторием пройдено |
| Работа быстрее 10 минут | Локальный прогон занимает секунды, внешних вызовов моделей нет |
| Нет доступа к скрытым эффектам из агента | agent.py использует публичный интерфейс env; оценщик и внутренние данные остаются в demo API |
| Зависимости доступны | requirements.txt, Dockerfile и Compose включены в репозиторий |
