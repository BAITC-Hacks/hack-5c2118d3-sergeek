# Sergeek Campaign Agent

Адаптивный агент для планирования тарифных маркетинговых кампаний Beeline в
условиях неполной информации. Агент проверяет гипотезы небольшими пилотами,
учитывает неопределённость результата и формирует портфель кампаний с выбором
канала коммуникации в рамках бюджета и лимита охвата.

## Задача

Для аудитории из 23 441 абонента требуется выбрать до 10 кампаний. Каждая
кампания определяет:

1. сегмент аудитории;
2. целевой тариф;
3. канал коммуникации.

При этом действуют ограничения: бюджет 100 000 у.е., общий охват до 15 000
контактов, до 20 пилотов и до 5 000 абонентов в одной кампании. Эффекты целевой
аудитории заранее неизвестны, поэтому статическая стратегия по историческим
данным недостаточна.

## Как работает решение

```text
Исторические данные
        ↓
15 приоритетных тарифных гипотез
        ↓
10 широких push-пилотов × 120 клиентов
        ↓
Повторная оценка и 4 подтверждающих пилота × 200 клиентов
        ↓
Weighted mean + uncertainty-adjusted lower bound
        ↓
Удаление конфликтующих аудиторий
        ↓
Совместная оптимизация skip / push / SMS / digital ads
        ↓
До 5 финальных кампаний в рамках бюджета и охвата
```

Push используется для разведки, поскольку не расходует денежный бюджет.
Результаты повторных пилотов объединяются взвешенным средним. Для принятия
решения применяется нижняя оценка эффекта с поправкой на стандартную ошибку —
это снижает риск масштабировать кампанию из-за случайно удачного пилота.

Финальный оптимизатор перебирает допустимые комбинации каналов, учитывая:

- остаток бюджета после пилотов;
- остаток лимита контактов;
- стоимость контакта;
- множитель конверсии канала;
- размер и средний predicted ARPU сегмента;
- запрет на конкурирующие кампании для одной аудитории.

Резервный сценарий всегда возвращает корректную push-кампанию, даже если серия
пилотов оказалась неудачной.

## Быстрый запуск

Требуется Docker Desktop с Docker Compose.

```bash
git clone https://github.com/BAITC-Hacks/hack-5c2118d3-sergeek.git
cd hack-5c2118d3-sergeek
docker compose up -d --build
```

Локальная проверка агента:

```bash
docker compose exec hackathon python local_eval.py
docker compose exec hackathon python local_eval.py --runs 10
```

Воспроизводимая генерация файла сдачи:

```bash
docker compose exec hackathon python make_submission.py
```

Контрактные smoke-тесты на десяти seed:

```bash
docker compose exec api python -m unittest discover -s tests -v
```

После запуска API доступно по адресу `http://localhost:8000`, интерактивная
OpenAPI-документация — `http://localhost:8000/docs`.

Аналитический dashboard доступен по адресу `http://localhost:5173`.

## API для dashboard

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка доступности |
| GET | `/api/dashboard` | KPI, лимиты и каналы |
| GET | `/api/campaigns?seed=42` | Финальный портфель кампаний |
| GET | `/api/pilots?seed=42` | Результаты пилотных запусков |
| GET | `/api/simulations/latest` | Последняя сводка устойчивости |
| POST | `/api/simulations/run` | Запуск 1–100 mock-симуляций |

Пример запуска симуляции:

```bash
curl -X POST http://localhost:8000/api/simulations/run \
  -H "Content-Type: application/json" \
  -d '{"runs": 10, "seed_start": 0}'
```

